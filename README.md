# Northwind Sales Analysis | SQL & Power BI

## Project Overview
This project focuses on analyzing sales data from the Northwind database using **SQL and Power BI**. The objective is to explore sales performance, identify revenue trends, evaluate product performance, and build an interactive dashboard to support data-driven business decisions.

## Tools & Technologies
- **SQL (MySQL):** Data querying, joins, aggregations, subqueries, and window functions.
- **Power BI:** Interactive dashboard development and data visualization.
- **DAX:** Measures and calculated metrics.
- **Power Query:** Data cleaning and transformation.
- **Excel:** Data inspection and validation.

## Key Analysis Areas
- Total Revenue Analysis
- Monthly Revenue Trends
- Product-wise Sales Performance
- Top 10 Products by Revenue
- Order and Sales Performance
- Revenue Contribution Analysis
- Previous Month Revenue Comparison
